# TaskPlus ⚡

A lightweight, offline-first Progressive Web App (PWA) for managing tasks and scheduling your workflow. Built with a sleek dark theme and designed to feel right at home on ChromeOS.

## ✨ Features

* **100% Offline Capable:** Runs entirely in your browser using local storage and Service Workers. No internet connection required.
* **Installable PWA:** Install it directly to your ChromeOS launcher, desktop, or mobile home screen as a native-feeling standalone app.
* **Subtasks:** Break complex tasks down into smaller, actionable steps with built-in progress tracking.
* **Smart Filtering:** Sort your workflow by Categories, Status (To Do, In Progress, Completed), Important items, or tasks due Today.
* **Interactive Calendar:** Visualize your deadlines with a dynamic grid view.
* **Dark Mode UI:** A clean, modern interface using slate and indigo tones.

## 🚀 How to Install

1. Visit the live GitHub Pages link for this repository.
2. Look at the right side of your Chrome address bar.
3. Click the **Install** icon (a computer monitor with a downward arrow).
4. TaskPlus is now in your app launcher!
